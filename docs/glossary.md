# المصطلحات والمفاهيم

| المصطلح | المعنى |
|---------|--------|
| **القسم التجاري** | القسم المعني بكل الأنشطة والإيرادات التجارية، ويضم أربع إدارات. |
| **إدارة مبيعات الوقود** | الإدارة المسؤولة عن مبيعات الوقود عبر المنافذ. |
| **إدارة التأجير** | الإدارة المسؤولة عن تأجير الوحدات التجارية داخل المنافذ. |
| **إدارة الشراكات** | الإدارة المسؤولة عن التحالفات التجارية (علامات، أساطيل، عروض مشتركة). |
| **إدارة التسويق** | الإدارة المسؤولة عن التسويق والمبيعات الرقمية وبرنامج «تانكي». |
| **منفذ** | المحطة؛ الوحدة التي نبني لها خطة بيع شاملة. |
| **محاور العمل** | مبيعات الوقود، التأجير، الشراكات، المبيعات عبر التطبيق، مكافآت تانكي. |
| **تانكي** | برنامج الولاء/المكافآت الخاص بعملاء «درب». |
| **تأجير الوحدات** | تأجير المساحات/الوحدات التجارية داخل المنفذ لمستأجرين. |
| **شراكة/امتياز (Franchise)** | اتفاق مع علامة تجارية لتشغيل نشاط داخل المنفذ. |
| **عقد أسطول / حساب مؤسسي** | اتفاق تزويد وقود لشركة/أسطول مركبات (B2B) لرفع الأحجام. |
| **استدامة المستأجر** | اختيار نشاط يناسب الموقع ويبقى قابلاً للحياة تجارياً طويل الأمد. |
| **خط الأساس (Baseline)** | القيمة الحالية للمؤشر قبل تطبيق المبادرات، تُستخدم للمقارنة. |
| **KPI** | مؤشر أداء رئيسي لقياس التقدم نحو الهدف. |
| **SMART** | أهداف محددة، قابلة للقياس، قابلة للتحقيق، ذات صلة، ومحددة زمنياً. |
| **نسبة الإشغال** | نسبة الوحدات المؤجّرة من إجمالي الوحدات القابلة للتأجير. |
| **معدل الاستبدال** | نسبة النقاط/المكافآت المستبدلة إلى المكتسبة. |
| **معدل الاحتفاظ** | نسبة العملاء الذين يواصلون التعامل خلال فترة معينة. |
| **AOV** | متوسط قيمة الطلب (Average Order Value). |

> نضيف لهذا القاموس أي مصطلح جديد يظهر أثناء العمل.
