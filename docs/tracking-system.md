# نظام تتبّع المبيعات (Sales Tracking System)

تحويل مؤشرات المحاور من **توثيق** إلى **متابعة حيّة**: لكل محطة حالة (إشارة
مرور) مقابل المستهدف، مع تنبيهات — لدعم القرار.

---

## 1. ماذا يتتبّع (لكل محطة)

- الإيراد، الزيارات، متوسط الفاتورة، الإيراد اليومي.
- **الاتجاه**: النمو (Q2 مقابل Q1) أو الاتجاه الشهري.
- ⛽ مزيج الوقود (95 / 91 / ديزل).
- 💳 طرق الدفع و**حصة التطبيق**.
- ⏰ ذروة الوقت واليوم الأعلى.
- 🤝 عدد حملات الشراكة.

## 2. منطق الحالة (إشارة المرور)

| الحالة | المعيار |
|-------|---------|
| 🟢 متقدّمة | النمو ≥ المستهدف |
| 🟡 تحت المستهدف | النمو بين صفر والمستهدف |
| 🔴 متراجعة | نمو سالب |
| ⚪ جديدة | بلا مقارنة (محطة حديثة) |
| ⚑ علَم | حصة التطبيق < ٢٪ |

## 3. المستهدفات

- **قابلة للضبط**: مستهدف نمو الإيراد (افتراضي في اللوحة).
- تُستكمل لاحقاً بمستهدف لكل محور لكل محطة بعد الاعتماد (المهمة #7).

## 4. مصدر البيانات والتحديث

- **الأساس:** [`outlets/data/analytics.csv`](../outlets/data/analytics.csv) — مستخرج من لوحة تحليلات «درب».
- **التحديث:** شهري — تُحدَّث الأرقام وتُعاد المتابعة.
- **التكامل المستقبلي:** ربط مباشر بـ«درب» (المعاملات، الحملات، تانكي) لتحديث آلي.

## 5. الإيقاع

- **شهري:** تحديث الأرقام ومراجعة الحالات الحمراء والأعلام.
- **ربعي:** مراجعة الأداء مقابل المستهدفات وتعديل المبادرات.

(انظر [آلية التنفيذ](execution.md).)

## 6. اللوحة التفاعلية

نسخة حيّة قابلة للفتح: فرز، فلترة (منطقة/حالة)، بحث، ضبط المستهدف، ونافذة
تفصيل لكل محطة (المؤشرات + مزيج الوقود + طرق الدفع + خلاصة المحاور). الرابط
يُشارَك من claude.ai.

## 7. مراحل التطوير

1. **v1 (الحالي):** تتبّع الأداء والاتجاه وحصة التطبيق، ببيانات شهرية.
2. **v2:** مستهدفات لكل محور لكل محطة (target ↔ actual كامل عبر المحاور الخمسة).
3. **v3:** ربط آلي بـ«درب» + تنبيهات تلقائية.
