# 📣 إدارة التسويق

> جزء من: **القسم التجاري**  ·  الركائز المرتبطة: 📱 المبيعات عبر التطبيق · 🎁 مكافآت تانكي

## المهمة

بناء الطلب والولاء، وتنمية المبيعات الرقمية عبر تطبيق «درب»، وإدارة برنامج
مكافآت «تانكي». وتعمل الإدارة كـ**طبقة داعمة** لجميع محركات البيع الثلاثة
(الوقود، التأجير، التطبيق) عبر الحملات والعروض والولاء والبيع المتقاطع.

## النطاق والمسؤوليات

- التسويق والاتصال وبناء العلامة عبر المنافذ.
- إدارة تطبيق «درب» ودعم/تنمية المبيعات الرقمية.
- إدارة برنامج مكافآت «تانكي» (اكتساب، تفعيل، استبدال، احتفاظ).
- تصميم الحملات والعروض الترويجية ومتابعة أثرها.
- تحليلات العملاء وتجزئتهم.

## المؤشرات الرئيسية

**المبيعات عبر التطبيق:**
- المستخدمون النشطون · نسبة المعاملات الرقمية · متوسط قيمة الطلب · تكرار الشراء

**مكافآت تانكي:**
- عدد الأعضاء ومعدل الاكتساب · الأعضاء النشطون · النقاط المكتسبة/المستبدلة ·
  معدل الاستبدال · معدل الاحتفاظ · حصة مبيعات الأعضاء

## الخطة الاستراتيجية

> **الحالة:** مسودة للاعتماد · المستهدفات الكمية مقترحة.

### الأهداف
1. رفع نسبة المبيعات عبر التطبيق والمستخدمين النشطين.
2. تنمية «تانكي» (اكتساب/تفعيل/احتفاظ) ورفع حصة مبيعات الأعضاء.
3. تفعيل البيع المتقاطع بين المحاور لكل منفذ.
