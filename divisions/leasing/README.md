# 🏪 إدارة التأجير

> جزء من: **القسم التجاري**  ·  الركيزة المرتبطة: 🏪 تأجير الوحدات

## المهمة

تعظيم إيراد وإشغال الوحدات التجارية داخل المنافذ، وبناء مزيج مستأجرين جاذب
يرفع قيمة المنفذ ويخدم الزوّار.

## مبدأ توجيهي

تغطية الشواغر تكون **مدروسة حسب احتياجات الموقع** لضمان **استدامة المستأجر**
— نختار النشاط الذي يخدم زوّار المنفذ ويبقى قابلاً للحياة تجارياً، لا مجرد ملء
الفراغ.

> بالتعاون مع **إدارة الشراكات** لاستقطاب علامات/امتيازات قوية تدعم الاستدامة.

## النطاق والمسؤوليات

- إدارة عقود الإيجار والتجديدات.
- جذب المستأجرين وتنويع مزيج العلامات.
- التسعير الإيجاري وشروط التعاقد.
- رفع نسبة الإشغال وتقليل الشواغر.
- تطوير مساحات/وحدات جديدة قابلة للتأجير.

## المؤشرات الرئيسية

- نسبة الإشغال (%)
- الإيراد الإيجاري (شهري/سنوي)
- الإيراد لكل م²
- عدد الوحدات المؤجّرة/الشاغرة
- معدل تجديد العقود ومتوسط مدتها

## الخطة الاستراتيجية

> **الحالة:** مسودة للاعتماد · المستهدفات الكمية مقترحة وتُضبط ببيانات المنفذ.

### الأهداف
1. تغطية الوحدات الشاغرة بمستأجرين مناسبين لاحتياجات كل موقع.
2. رفع نسبة الإشغال والإيراد لكل م².
3. ضمان استدامة المستأجر وتقليل معدل الإخلاء.
