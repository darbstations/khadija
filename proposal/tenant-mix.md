# خلطة المستأجرين المقترحة — مدينة الملك عبدالله الطبية (مكة المكرمة)
### قائمة علامات فعلية لاستقطابها للمساحات الاستثمارية (F&B + هدايا الزوّار)

> الدور: أنت مشغّل الموقع — تستلم المساحات، تصمّمها، وتنتقي/تستقطب هذه العلامات (تشغيل مباشر، امتياز، أو تأجير من الباطن).

## معايير الاختيار لهذا الموقع تحديداً
- **حلال افتراضياً** (السوق السعودي) — ميزة تلقائية.
- **سرعة وخدمة سفري/جراب-آند-قو** — الزائر متوتر ووقته ضيق.
- **عائلات وأطفال + ضيوف رحمن ومعتمرون** من كل الجنسيات → مزيج محلي محبوب + عالمي مألوف.
- **ثقافة الإهداء للمريض** (ورد، شوكولاتة، تمور) → فرصة تجزئة بهامش مرتفع.
- **روائح خفيفة / لا شواء ثقيل / لا شيشة** — احترام البيئة الصحية.
- **إمكانية كشك/مساحة صغيرة (small-format)** — يناسب ممرات ومداخل المستشفى.
- **تدرّج أسعار**: اقتصادي + متوسط + راقٍ لتغطية كل الشرائح.

## 7) خدمات مساندة (اختياري — دخل إضافي)
- **صيدلية:** النهدي / الدواء (كشك أو فرع صغير) — قيمة عالية للزوّار.
- **بقالة راحة / أساسيات الزائر** 24/7 (مياه، مناديل، شواحن، مستلزمات مبيت المرافق).
- **مكائن بيع ذاتي ذكية** (كما في خطة المدينة): غذاء صحي، عناية شخصية، مستلزمات صيدلانية، ورود/هدايا.

## خريطة التوزيع على مساحات المدينة (مقترح)
| المساحة | الخلطة المقترحة |
|---|---|
| **البوليفارد (المرساة)** | مرساة قهوة (Brew92 / % Arabica / بارنز) + مرساة صحية (Fresh House) + 1–2 كومفورت (كودو/شاورمر/مايسترو) + عصائر/مخبوزات (Boost/سعد الدين) + عنقود هدايا (Floward + باتشي/Bateel) + ركن قهوة عربية |
| **مقهى العيادات الخارجية** | قهوة هادئة + وجبات خفيفة (بارنز / دوز / % Arabica) لتحسين تجربة الانتظار |
| **إحلال مقهى قهوة الأمراء + بون** | ترقية لعلامات قهوة أقوى (بارنز/دوز/Camel Step) بدل التشغيل الحالي |
| **المداخل والمواقف** | أكشاك قهوة سريعة + بقالة راحة + ورد سريع عند المخارج |
| **البيع الذاتي 24/7** | غذاء صحي + عناية + صيدلاني + ورود/هدايا |

## ملاحظات تشغيلية سريعة
- **رتّب العلامات في 3 مستويات سعرية** لتغطية الكادر (اقتصادي)، العوائل (متوسط)، والزوّار المهدين (راقٍ).
- **أولوية الاستقطاب** للعلامات ذات صيغة الكشك/المساحة الصغيرة والقابلة للامتياز.
- **البيك** أيقونة جذب حركة لكنه صعب الامتياز — تُطرح كأولوية تفاوضية، مع بديل جاهز.
- **علامتك الخاصة** في القهوة العربية + الورد = أعلى هامش وتحكّم.
- احترم **أوقات الصلاة** وقرب **المصلى** في توزيع الجلسات.
