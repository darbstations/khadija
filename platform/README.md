# منصة درب لمؤشرات الأداء (Darb KPI Platform)

منصة ويب تفاعلية لإدارة استراتيجية درب 2026 — لوحة تنفيذية، تغذية الأرقام بصلاحيات،
مبادرات ومخاطر، واستيراد من ملف الإكسل. مبنية على FastAPI + SQLite.

## التشغيل محلياً
```bash
cd platform
./run.sh           # يثبّت المتطلبات ويشغّل الخادم على http://localhost:8000
```
أو يدوياً:
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

## الحسابات التجريبية (الصلاحيات)
| المستخدم | كلمة المرور | الدور | الصلاحية |
|---|---|---|---|
| `admin` | `admin123` | مدير النظام | كل شيء: تعديل المؤشرات/المستهدفات/الأوزان + استيراد |
| `exec` | `exec123` | الإدارة التنفيذية | تغذية مؤشرات الإدارة التنفيذية + ضبط شهر التقرير + عرض الكل |
| `franchise` | `franchise123` | مدير إدارة | تغذية مؤشرات إدارته فقط (وهكذا: operations / investment / realestate / digital / hr) |
| `emp` | `emp123` | موظف | تغذية مؤشرات إدارته فقط |

> الصلاحيات مطبّقة في الخادم: من لا يملك صلاحية لا تُحفظ تعديلاته. تعريف المؤشر والمستهدف
> مقفولان لغير مدير النظام — كلٌّ يُدخل أرقامه فقط دون المساس بالمؤشر أو المستهدف.

## المزايا
- **لوحة تنفيذية:** الإنجاز العام + عدّادات الحالة + رسوم الركائز والإدارات + منظورات BSC + تغطية المشاريع.
- **تغذية تفاعلية:** صفحة لكل إدارة بإدخال شهري (12 شهر) — YTD ونسبة التحقيق والحالة تُحسب آلياً.
- **شهر التقرير:** ضابط للتنبؤ والانحراف (للأدمن/التنفيذي).
- **إدارة المؤشرات (أدمن):** تعديل المستهدف/الوزن/خط الأساس + نص المستهدف.
- **المبادرات والمخاطر:** سجلّات قابلة للإضافة والتعديل.
- **الاستيراد:** رفع ملف الإكسل واستيراد الأرقام الشهرية بمطابقة اسم المؤشر.

## النشر (الرفع/الاستضافة)
- **Render / Railway / Fly.io:** أمر التشغيل `uvicorn app.main:app --host 0.0.0.0 --port $PORT`.
- **Docker:** أنشئ صورة من `python:3.11-slim`، انسخ المجلد، `pip install -r requirements.txt`، شغّل uvicorn.
- **خادم VPS:** خلف Nginx مع gunicorn/uvicorn workers.
- غيّر `DARB_SECRET` لمفتاح سري قوي في الإنتاج، واستبدل SQLite بـ PostgreSQL للأحمال الأعلى.

## البنية
```
platform/app/
  main.py        مسارات FastAPI + الحسابات
  models.py      جداول قاعدة البيانات
  kpi_data.py    تعريفات المؤشرات (118 مؤشراً / 7 إدارات)
  seed.py        تهيئة القاعدة + المستخدمين
  compute.py     YTD / نسبة التحقيق / الحالة / التنبؤ
  auth.py        كلمات المرور + الصلاحيات
  templates/     واجهات Jinja2 (RTL بهوية درب)
  static/        التصميم + الشعار
```

## ملاحظة
قاعدة البيانات `app/darb.db` تُنشأ تلقائياً عند أول تشغيل (مع بيانات تجريبية). لإعادة التهيئة احذف الملف.
