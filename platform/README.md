# منصّة مبيعات القسم التجاري — درب (تانكي)

منصّة ويب مستقلّة **متعددة المحطات** لتحليل وإدارة المبيعات على مستوى كل منفذ (محطة)، بتصميم مطابق لموقع درب (داكن + برتقالي + خط Tajawal، اتجاه RTL).

## 🔗 الروابط

| الوحدة | الرابط | الغرض |
|---|---|---|
| **وحدة العرض الاستراتيجي** | https://darbstations.github.io/khadija/commercial/ | **للعرض على الإدارة التنفيذية** — الإطار والمنهجية والخطط بلا أرقام (عرض فقط) |
| **المحرّر التفاعلي** | https://darbstations.github.io/khadija/commercial/editor/ | أداة العمل — كل الحقول قابلة للتعديل والحساب اللحظي |

> الأرقام والمستهدفات وخطط كل منفذ تُدار في **ملف البيانات (إكسل)** وفي `editor/data.json`.

## ✨ الفكرة
- **نظرة عامة أولاً** — كرت لكل محطة (الإيراد · خط أنابيب المبيعات · حالة رابحة/خاسرة)، تضغط الكرت فتدخل على تحليلها الكامل.
- **تحليل مبيعات كامل لكل محطة** بالترتيب: مَن نبيع له → المحيط التنافسي وبطاقة السيناريو → 🎯 خريطة فرص المبيعات → أداء الخطط → الربحية.
- **🎯 خريطة فرص المبيعات (B2B)** — الجوار التجاري (أساطيل، مطاعم، موردون، متاجر) كأهداف بيع: قناة البيع، القيمة الشهرية، الحالة (فرصة/تواصل/عرض/متعاقد)، والأولوية — مع إجمالي خط الأنابيب والمتعاقد والفرص المفتوحة وتوزيعها بالقناة. يمكن إضافة/حذف فرص.
- **كل معلومة حقل قابل للتعديل يدوياً** — لا صور ثابتة؛ حتى بطاقة السيناريو والكروت والنصوص.
- **الرسوم تتحدّث لحظياً** — الدونات، الخط الشهري، أشرطة الدفع، الإشغال، ومؤشرات خط الأنابيب.
- **الربحية تفاعلية** — تقول فوراً: المحطة **رابحة 🟢** أو **خاسرة 🔴** مع الصافي وتكلفة اللتر ونقطة التعادل، وتُجمّع على مستوى المحفظة كاملة.
- **إضافة/حذف محطات** + **حفظ تلقائي** (localStorage) + **تصدير `data.json`** للنشر.

## 🗂️ الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | **وحدة العرض** — صفحة ثابتة بلا حقول ولا أرقام (للعرض التنفيذي، تدعم الطباعة) |
| `editor/index.html` | **المحرّر التفاعلي** كاملاً (ملف واحد قائم بذاته بلا اعتماديات) |
| `editor/data.json` | بيانات المحطات — تُقرأ وتُعرض وتُحرّر في المحرّر |

الصفحة تقرأ `data.json` عند الفتح؛ كل حقل مربوط بمسار داخل هذا الملف عبر خاصية `data-p` (مثل `finance.liters`)، والتعديل يكتب في نفس المسار ثم يعيد رسم كل شيء.

## 🚀 كيفية النشر (تحديث الموقع)
1. عدّل البيانات داخل المنصّة، ثم اضغط **«⬇️ تصدير data.json»**.
2. استبدل `commercial/editor/data.json` في فرع `gh-pages` بالملف المُصدَّر (أو حدّث `platform/editor/data.json` هنا).
3. ادفع التغيير — GitHub Pages يُعيد النشر خلال ~دقيقة والرابط يتحدّث تلقائياً.

> النسخة المنشورة تعيش في فرع `gh-pages`: وحدة العرض في `commercial/` والمحرّر في `commercial/editor/`. هذا المجلّد (`platform/`) هو **المصدر** المحفوظ ضمن فرع العمل لأغراض التتبّع والاسترجاع.

## 🧭 بنية المنصّة
- **٠٠ نظرة عامة** — كروت المحطات (اختيار المحطة).
- **٠١ مَن نبيع له** — الشرائح + الديموغرافيا.
- **٠٢ المحيط التنافسي وبطاقة السيناريو** — محطتنا مقابل المنافسين + الميزة + الفجوة + البراندات المقترحة + موقعنا على الطريق.
- **٠٣ 🎯 خريطة فرص المبيعات (B2B)** — الجوار التجاري كأهداف بيع + إجمالي خط الأنابيب/المتعاقد/المفتوح + توزيع بالقناة.
- **٠٤ أداء خطط المبيعات** — الوقود · الدفع · التأجير · تانكي · الشراكات.
- **٠٥ نموذج الربحية التفاعلي** — الدخل مقابل المصاريف → رابحة/خاسرة.
