# المنصّة التجارية التفاعلية — درب (تانكي)

منصّة ويب مستقلّة لعرض وتحرير استراتيجية القسم التجاري على مستوى كل منفذ (محطة)، بتصميم مطابق لموقع درب (داكن + برتقالي + خط Tajawal، اتجاه RTL).

## 🔗 الرابط المباشر
https://darbstations.github.io/khadija/commercial/

## ✨ الفكرة
- **كل الحقول قابلة للتعديل يدوياً** — الاسم، الأرقام، البراندات، النِسب، الشرائح... كلها حقول إدخال حيّة وليست صوراً ثابتة.
- **الرسوم تتحدّث لحظياً** — الدونات (مزيج الوقود)، الخط الشهري (Sparkline)، أشرطة طرق الدفع، مؤشّر الإشغال.
- **نموذج الربحية تفاعلي** — يعيد الحساب فوراً ويقول: المحطة **رابحة 🟢** أو **خاسرة 🔴** مع صافي الربح/الخسارة وتكلفة التشغيل لكل لتر ونقطة التعادل.
- **حفظ تلقائي** في متصفّح المستخدم (localStorage) — لا تضيع التعديلات عند إعادة الفتح.
- **تصدير `data.json`** — زر يُنزّل نسخة من بياناتك؛ تُلصق في المستودع لتُنشر تلقائياً للجميع.

## 🗂️ الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | المنصّة كاملة (HTML + CSS + JS، ملف واحد قائم بذاته، بلا اعتماديات) |
| `data.json` | كل بيانات المحطة (MK007 نموذجاً) — هذا ما يُقرأ ويُعرض ويُحرّر |

الصفحة تقرأ `data.json` عند الفتح؛ كل حقل مربوط بمسار داخل هذا الملف عبر خاصية `data-p` (مثل `finance.liters`)، والتعديل يكتب في نفس المسار ثم يعيد رسم كل شيء.

## 🚀 كيفية النشر (تحديث الموقع)
1. عدّل البيانات داخل المنصّة، ثم اضغط **«⬇️ تصدير data.json»**.
2. استبدل `commercial/data.json` في فرع `gh-pages` بالملف المُصدَّر (أو حدّث `platform/data.json` هنا).
3. ادفع التغيير — GitHub Pages يُعيد النشر خلال ~دقيقة والرابط يتحدّث تلقائياً.

> النسخة المنشورة تعيش في فرع `gh-pages` تحت مجلّد `commercial/`. هذا المجلّد (`platform/`) هو **المصدر** المحفوظ ضمن فرع العمل لأغراض التتبّع والاسترجاع.

## 🧭 محاور المنصّة
1. **مَن تخدمه المحطة** — الشرائح + الديموغرافيا.
2. **المحيط التنافسي** — براندات محطتنا مقابل المنافسين + الميزة + الفجوة + براندات مقترحة.
3. **أداء المحاور الخمسة** — الوقود · الدفع · التأجير · تانكي · الشراكات.
4. **نموذج الربحية التفاعلي** — الدخل مقابل المصاريف → كسبانة/خسرانة.

الخطوة القادمة: **دمج المكس التسويقي (4Ps / الحملات)** ضمن المنصّة.
