# تشغيل منصة درب (موقع واحد تفاعلي)

## ماك / لينكس
```bash
cd platform
./run.sh
```
## ويندوز
انقر مزدوج على `run.bat`  (أو من الموجّه: `run.bat`)

ثم افتح المتصفح على:  **http://localhost:8000**

## الدخول
- مدير النظام: `admin` / `admin123`
- الإدارة التنفيذية: `exec` / `exec123`
- مدير التسويق: `marketing` / `marketing123`
- موظفة تسويق: `amani` / `amani123`

> موقع واحد كامل: سجّل الدخول وتنقّل من القائمة العلوية بين اللوحة والإدارات والموظفين والتقييم… وكل التغذية والحفظ تشتغل فعلياً بالصلاحيات.

## بديل (Docker)
```bash
cd platform
docker compose up -d      # ثم http://localhost:8000
```
