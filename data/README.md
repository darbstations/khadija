| ١٣ | بطاقة الأداء المشتركة | المؤشرات المشتركة لكل منفذ + إجمالي المحفظة |

## ✨ العناصر التفاعلية
- **رسوم بيانية أصلية** في لوحة التحكم (عمودية · دائرية · خطية · شريطية)
- **تنسيق شرطي**: أشرطة بيانات للمبيعات · حصة التطبيق حمراء دون المستهدف وخضراء فوقه · نسبة الإيجار حمراء فوق ١٥٪ · الوحدات الشاغرة حمراء
- **قوائم منسدلة** للحالات والتصنيفات (مؤجّرة/شاغرة · فرصة/تواصل/عرض/متعاقد · أنواع الوحدات · منتجات الوقود)
- **فلاتر تلقائية** وتجميد الرؤوس على كل جدول بيانات
- **إخفاء الشبكة** وتنسيق طباعة (أفقي · ملاءمة للعرض) لكل ورقة

## 🎨 دليل الألوان

| اللون | المعنى |
|---|---|
| 🔵 **أزرق** | مُدخل يدوي — عدّله |
| ⚫ **أسود** | معادلة محسوبة — لا تُعدَّل |
| 🟢 **أخضر** | رابط لورقة أخرى |
| 🟡 **أصفر** | يحتاج تعبئة عند الاعتماد |

## ⚙️ المعادلات (حيّة، لا أرقام مثبّتة)
- **الربح لكل زيارة** = الصافي ÷ الزيارات
- **نسبة الإيجار** = الإيجار ÷ مبيعات آخر شهر *(الصحّي ≤ ١٥٪)*
- **ربح كل منتج وقود** = الحصة × إجمالي اللترات × الهامش
- **تغطية غير الوقود** = (الإيجار + الخدمات) ÷ المصاريف
- **نقطة التعادل** = (المصاريف − غير الوقود) ÷ هامش اللتر

> **بطاقة الأداء المشتركة مرتبطة بالنموذج المالي** — أي تعديل في المُدخلات ينعكس على كل المؤشرات تلقائياً.

## 🔄 إعادة البناء
```bash
python3 build_xlsx.py     # يقرأ data.json ويعيد توليد الملف
```
> الملف مُولَّد من `platform/editor/data.json` — حدّث البيانات هناك ثم أعد التوليد، أو عدّل الإكسل مباشرة.

## ⚠️ ملاحظة
الأرقام المالية (الهوامش · الإيجارات · المصاريف) وأرقام التشغيل (المضخات · الخزان · العمّال) **تقديرات نموذجية للاعتماد** — تُستبدل بالأرقام المعتمدة من المالية وسجل الأصول.

# ⭐ ملف استراتيجية العمرة الجديدة (MK007)

**`استراتيجية-العمرة-الجديدة-MK007.xlsx`** — استراتيجية منفذ واحد كـ**نموذج حيّ**: غيّر أي افتراض فيعاد حساب الأثر بالكامل.

| # | الورقة | المحتوى |
|---|---|---|
| ١ | **الملخص التنفيذي** | ٨ مؤشرات + رسم «الفعلي مقابل المستهدف» + المسألة الاستراتيجية والخيار |
| ٢ | **نموذج المحرّكات** ⭐ | الافتراضات (زرقاء) → عقود الأساطيل → احتساب الأثر بالمعادلات |
| ٣ | خط الأساس | الأرقام الفعلية + مزيج الوقود |
| ٤ | التشخيص | خمس ملاحظات بأدلّتها من البيانات وأثرها |
| ٥ | خطط الإدارات | مبادرات ومؤشرات الإدارات الأربع + ميزانية الترويج |
| ٦ | المستهدفات | الأساس/المستهدف/الفجوة + نسب إيجار المستأجرين |
| ٧ | خارطة الطريق | أربعة أرباع بالمسؤول والحالة |
| ٨ | المخاطر | سجل بالاحتمال والأثر والتخفيف |
| ٩ | القرارات المطلوبة | خمسة قرارات بخانة اعتماد/تعديل/تأجيل |

**كيف تستخدمه:** عدّل في «نموذج المحرّكات» حجم الوقود المستهدف · الهامش · إيجار المرساة · حجوم الأساطيل وحالاتها — فتتحدّث «إجمالي الأثر» و«الصافي المستهدف» و«الربح لكل زيارة» والملخص التنفيذي فوراً.

> ⚠️ حجم الأساطيل **جزء من** فجوة الحجم ولا يُضاف فوقها — تفادياً لازدواج الحساب.
