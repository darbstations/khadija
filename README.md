# تانكي · درب — النموذج المالي التفاعلي

برنامج الولاء **تانكي** لتطبيق **درب** (محطات وقود) — نموذج مالي تفاعلي + ملف إكسل بمعادلات حقيقية.

اقتصاد النقاط: **الوقود يجذب، والشركاء يموّلون**. كسب الوقود قليل (~0.5–1٪) لأن هامش
الوقود رفيع (5–6٪)، بينما الكرم (3–5٪) يأتي من الشركاء ومموَّل منهم.

## التطبيق التفاعلي (React + Vite + TypeScript)

كل الشاشات تشتق من محرك حسابي واحد (`src/model/engine.ts`) يطابق معادلات الإكسل خلية بخلية.
غيّر القيم في **لوحة السيناريوهات** فتتحدث كل الشاشات فوراً (وتُحفظ في المتصفح).

```bash
npm install
npm run dev       # خادم التطوير
npm run build     # بناء للإنتاج (dist/)
npm run preview   # معاينة البناء
```

### الشاشات
الملخص التنفيذي · السيناريوهات (المدخلات) · محاكي العميل · المستويات وقيمة النقطة ·
الاقتصاد الموسّع (الديزل + الشركاء) · تكلفة المحطات · التحصيل من الامتياز · التوقعات السنوية ·
حاسبة ROI · مقارنة السيناريوهات · كيف يعمل + خطة التوسع.

## ملف الإكسل (معادلات حقيقية)

`tanki_financial_model_v5.xlsx` — مولَّد عبر سكربت من المصدر:

```bash
npm run gen:excel   # = python3 scripts/build_excel.py
```

النسخة v5 تطبّق: معدلات الكسب 50/75/100، هوامش درب الفعلية (13 هللة)، إصلاح أخطاء
معادلات المؤشرات، وورقة **«الاقتصاد الموسّع»** بمعادلات LIVE تشير لخلايا السيناريوهات
(الديزل + الشركاء) — كلها معادلات حقيقية لا أرقام ثابتة.
