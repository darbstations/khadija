# خديجة — نظام مؤشرات أداء سلاسل الإمداد (درب الوقود) ٢٠٢٦

مصنّف Excel لتتبّع **٩ مؤشرات أداء** عبر **٥ محاور** (خدمة العميل، التكاليف، السيولة المالية،
السلامة والامتثال، الكفاءة التشغيلية)، تُحسب قيمها الفعلية **آلياً** من ٥ صفحات إدخال،
وتُقارن بـ**خطة يدوية** شهرية مع حالة ✅/🟡/🔴 ونسبة انحراف، وحالة مُجمَّعة لكل محور.

> بدأ النظام بـ١٣ مؤشراً ثم دُمجت المؤشرات المتكرّرة (التي تؤدي نفس الهدف) إلى ٩ — التفاصيل
> في قسم «الدمج الاستراتيجي». النسخة ذات الـ١٣ محفوظة في سجل Git.

## محتويات المستودع

| المسار | الوصف |
|---|---|
| `workbook/khadija-supply-chain-kpis-2026.xlsx` | المصنّف (لوحة ٩ مؤشرات + مرجع الإدارة + ٥ صفحات إدخال) |
| `workbook/source-management-kpis.xlsx` | القائمة الرسمية لمؤشرات الإدارة (٥ مؤشرات) كما وردت |
| `scripts/update_management_kpis.py` | مواءمة طريقة القياس مع مرجع الإدارة + إضافة ورقة المرجع |
| `scripts/build_condensed_dashboard.py` | يبني لوحة الـ٩ الموحّدة ويحذف لوحة الـ١٣ |
| `scripts/verify_formulas.py` | تحقق وظيفي يثبت صحة الدوال عبر محرّك Excel حقيقي (pycel) |

## بنية المصنّف

**لوحة `📊 مؤشرات الأداء (٩)`** — صفّان لكل مؤشر: «خطة» (إدخال يدوي) و«فعلي» (دالة آلية) على
١٢ عموداً شهرياً. عمود **«الهدف» رقم فعلي** (مثل `99.50%`/`100`/`3`)، وكل صف محور يعرض **حالة
مُجمَّعة** (أسوأ حالة بين مؤشراته). خلية الإدخال `F31` = «عدد نقاط المنتج» تُستخدم في حساب التوفّر.

**ورقة `📋 مؤشرات الإدارة`** — المرجع الرسمي المعتمد (٥ مؤشرات) منقول حرفياً من ملف الإدارة،
مع عمود يربط كل مؤشر بما يقابله في اللوحة (K1…K9).

**٥ صفحات إدخال** تُغذّي اللوحة عبر `SUMIFS`/`COUNTIFS`/`AVERAGEIF`، بأعمدة محسوبة آلياً
وقوائم منسدلة منضبطة:

| الصفحة | محسوب آلياً |
|---|---|
| `🛢️ انقطاعات الوقود` | المدة (يوم) = تاريخ الانتهاء − البدء |
| `💧 الردود والفاقد` | الفاقد لكل ٣٣ألف لتر، والحالة |
| `📦 المخزون` | رقم الشهر، أيام المخزون، الحالة |
| `🛒 الطلبات والمشتريات` | أيام المعالجة، ضمن الهدف؟ |
| `🚚 النقل والرحلات` | في الوقت؟ |

## المؤشرات التسعة

الأهداف **تشغيلية**: المؤشرات التي غايتها صفر تقيس عدداً (انقطاعات/مخالفات/متأخرات)،
ومؤشرات الزمن تقيس متوسط الأيام.

| # | المؤشر | المحور | المقياس | الهدف | الاتجاه |
|---|---|---|---|---|---|
| K1 | توفر الوقود — عدد الانقطاعات | خدمة العميل | انقطاع | 0 | الأقل أفضل |
| K2 | توفر المواد المخزنية — أيام التسليم | خدمة العميل | يوم | ≤ 3 | الأقل أفضل |
| K3 | إصدار أوامر الشراء — أيام الإصدار | خدمة العميل | يوم | ≤ 5 | الأقل أفضل |
| K4 | فواقد الوقود لكل ٣٣K لتر | التكاليف | لتر | ≤ 100 | الأقل أفضل |
| K5 | نسبة المواد التالفة (يدوي) | التكاليف | % | ≤ 2% | الأقل أفضل |
| K6 | أيام مخزون الوقود | السيولة المالية | يوم | ≤ 3 | الأقل أفضل |
| K7 | الامتثال والسلامة — المخالفات/الحوادث | السلامة والامتثال | مخالفة | 0 | الأقل أفضل |
| K8 | التزام جدول النقل — الرحلات المتأخرة | الكفاءة التشغيلية | رحلة | 0 | الأقل أفضل |
| K9 | استخدام الأسطول المملوك | الكفاءة التشغيلية | % | ≥ 60% | الأعلى أفضل |

> المؤشرات ذات الهدف 0 تعرض حالتها كـ **✅ 0** أو **🔴 (العدد السنوي)**.

## طريقة القياس والأهداف التشغيلية

أُعيد تعريف بعض المؤشرات لتقيس **الغاية التشغيلية مباشرة** (فيتطابق المقياس مع وحدة الهدف):

- **توفر الوقود (K1):** = **عدد الانقطاعات الشهرية**، الهدف **0**.
- **المواد المخزنية (K2) / أوامر الشراء (K3):** = **متوسط أيام التسليم/الإصدار**، الهدف **≤ 3 / ≤ 5**.
- **الامتثال والسلامة (K7) / التزام الجدول (K8):** = **عدد المخالفات/الحوادث / الرحلات المتأخرة**، الهدف **0**.
- **فواقد الوقود (K4):** = **إجمالي الفاقد الشهري ÷ عدد الردود** (طريقة قياس الإدارة).

> ملاحظة: هذا يخالف صياغة الإدارة كنِسَب (مثل توفر الوقود ≥ 99.5%)؛ صياغة الإدارة الأصلية
> محفوظة كما وردت في ورقة `📋 مؤشرات الإدارة` للرجوع.

## الدمج الاستراتيجي للمؤشرات (١٣ → ٩)

دُمجت المؤشرات التي تؤدي نفس الهدف:

| المؤشر المُلغى/المطوي | السبب | المصير |
|---|---|---|
| عدد الانقطاعات الشهرية | نفس ظاهرة الانقطاعات التي يقيسها «التوفر» (تكرار مقابل شدّة) | مطوي داخل **توفر الوقود** |
| معدل دوران المخزون | متطابق رياضياً مع أيام المخزون (الدوران = ٣٠ ÷ الأيام) | مطوي داخل **أيام المخزون** |
| نسبة استيفاء الطلبات (Fill Rate) | كان تجميعة لمؤشري «المواد المخزنية» + «أوامر الشراء» | **محذوف** (مكرّر) |
| عدد حوادث النقل | يُحسب من نفس عمود المخالفات (ازدواج عدّ) | مطوي داخل **الامتثال والسلامة** |

> حُذفت لوحة الـ١٣ بناءً على الطلب؛ وهي محفوظة بالكامل في سجل Git ويمكن استرجاعها.

## إعادة الإنتاج

```bash
pip install openpyxl
python3 scripts/update_management_kpis.py      # مواءمة الإدارة + ورقة المرجع
python3 scripts/build_condensed_dashboard.py   # بناء لوحة الـ٩ وحذف الـ١٣
```

## التحقق من صحة الدوال

```bash
pip install openpyxl pycel
python3 scripts/verify_formulas.py
```

يحقن السكربت بيانات تجريبية في الصفحات الخمس (بما فيها حالات حدّية: يناير ٣١ يوماً، فبراير
٢٨، شهر فارغ، وقسمة على صفر)، ثم يُقيّم خلايا اللوحة فعلياً عبر محرّك **pycel** ويقارنها بحساب
مستقل — ١٦ خلية (١١ مؤشراً + ٥ حالات محاور)، وكلها مطابقة (RESULT: ✅). والقيم تُعاد حسابتها
تلقائياً عند فتح الملف في Excel (`fullCalcOnLoad`).
