# خديجة | قاعدة استراتيجيات القسم التجاري

منصّة معرفية لإدارة وتوثيق استراتيجيات **القسم التجاري** في «درب». نُنظّم فيها
**خطة بيع شاملة** لكل **منفذ** (محطة)، موزّعة على إدارات القسم الأربع — لتكون
مرجعاً واحداً للتخطيط والمتابعة واتخاذ القرار.

> **الفكرة المحورية:** ثلاث خطط بيع (⛽ وقود · 🏪 تأجير · 📱 تطبيق) تدعمها
> طبقتا **التسويق** و**الشراكات**، لتحقيق **مبيعات شاملة لكل محطة**.
> التفاصيل في [نموذج العمل الاستراتيجي](docs/framework.md#2-نموذج-العمل-الاستراتيجي).

---

## الهيكل التنظيمي للقسم

يتكوّن القسم التجاري من **أربع إدارات**:

| الإدارة | المسؤولية | المحور/المحاور |
|---------|-----------|------------------|
| 🛢️ **إدارة مبيعات الوقود** | أحجام البيع، الهوامش، التسعير، خدمة المضخات | ⛽ مبيعات الوقود |
| 🏪 **إدارة التأجير** | الإشغال، العقود، مزيج المستأجرين، الإيراد | 🏪 تأجير الوحدات |
| 🤝 **إدارة الشراكات** | علامات وامتيازات وأساطيل وعروض مشتركة | 🤝 الشراكات (تُغذّي الجميع) |
| 📣 **إدارة التسويق** | المبيعات الرقمية، ولاء «تانكي»، الحملات | 📱 التطبيق + 🎁 تانكي |

---

## ما هو «المنفذ»؟

المنفذ = **المحطة**. نقيس أداءه التجاري عبر خمسة محاور تملكها الإدارات الأربع:

| المحور | الإدارة المسؤولة | الوصف المختصر |
|--------|------------------|----------------|
| ⛽ **مبيعات الوقود** | مبيعات الوقود | بيع البنزين/الديزل: الأحجام، الهوامش، التسعير |
| 🏪 **تأجير الوحدات** | التأجير | تأجير الوحدات التجارية: الإشغال، المستأجرون، الإيراد |
| 🤝 **الشراكات** | الشراكات | علامات/أساطيل/عروض مشتركة تُغذّي بقية المحاور |
| 📱 **المبيعات عبر التطبيق** | التسويق | دعم وتنمية المبيعات عبر تطبيق «درب» |
| 🎁 **مكافآت تانكي** | التسويق | برنامج الولاء: الاكتساب، التفعيل، الاستبدال، الاحتفاظ |

## كيف نشتغل

1. **الإطار أولاً** — نتفق على الهيكل والمحاور والمؤشرات في [`docs/framework.md`](docs/framework.md).
2. **إدارة إدارة** — نبني خطة كل إدارة على مستوى القسم في [`divisions/`](divisions/).
3. **منفذ منفذ** — لكل محطة ننسخ [`_TEMPLATE.md`](outlets/_TEMPLATE.md) ونعبّي:
   بطاقة المنفذ ← خط الأساس ← تحليل ← أهداف ومستهدفات ← خطة تنفيذ.
4. **المتابعة** — نحدّث المؤشرات دورياً، ونقدر لاحقاً نربطها ببيانات نظام «درب».
